# MemLite

macOS 메뉴 막대에서 메모리 사용량을 보여주는 개인용 앱입니다. 별도 창과 Dock 아이콘은 없습니다.

메뉴 막대에는 아이콘 없이 `19.7 / 24.0 GB`처럼 사용량과 전체 용량만 표시합니다. 사용량 숫자는 시스템 메모리 압력에 따라 녹색, 주황색, 빨간색으로 바뀝니다. 클릭하면 활성상태보기와 같은 상세 항목과 정크 용량(휴지통, 사용자 캐시, 사용자 로그, 정크 합계)을 봅니다. 정크 파일 정리와 로그인 시 열기를 고를 수 있고, 메뉴 아래에는 `MemLite 1.0`이 한 줄로 보입니다.

## 요구 사항

- macOS 14.0 (Sonoma) 이상
- Xcode (설치 파일 생성 시)
- 공증하지 않은 개인용 빌드입니다. App Store 배포는 대상이 아닙니다.

## 저장소 받기

```bash
git clone https://github.com/tiper2066/MemLite.git
cd MemLite
```

Xcode에서 `MemLite.xcodeproj`를 열어 실행할 수도 있습니다.

## 설치 파일 만들기

클론한 뒤 프로젝트 루트에서 아래 스크립트를 실행합니다. Release 빌드 후 `MemLite.app`과 응용 프로그램 폴더 바로 가기가 들어 있는 DMG를 만듭니다.

```bash
./scripts/create-dmg.sh
```

완료되면 아래 파일이 생깁니다.

```text
dist/MemLite.dmg
```

`dist/`는 Git에 올리지 않습니다. 설치 파일이 필요하면 이 스크립트로 다시 만듭니다.

## 설치

1. `dist/MemLite.dmg`를 엽니다.
2. `MemLite`를 `Applications`로 끌어다 넣습니다.
3. 응용 프로그램 폴더에서 MemLite를 실행합니다.

서명이 로컬 실행용(ad-hoc)이라 Gatekeeper가 막을 수 있습니다. 그때는 앱을 우클릭한 뒤 **열기**를 선택합니다.

앱은 메뉴 막대에만 나타납니다. Dock과 앱 전환기에는 보이지 않습니다. 로그인 시 자동으로 열려면 메뉴에서 **로그인 시 열기**를 켭니다. 이 항목은 응용 프로그램 폴더에 설치한 앱에서만 켜집니다.

## 정크 파일 정리

메뉴를 열면 아래 위치의 지울 수 있는 용량이 보입니다. **정크 파일 정리…**를 고른 뒤에만 지웁니다.

- `~/.Trash`
- `~/Library/Caches`
- `~/Library/Logs`

심볼릭 링크, 잠긴 파일, 다른 프로세스가 연 파일, 계정·동기화·보안에 영향을 줄 수 있는 캐시는 빼 둡니다. 확인 대화상자에서 **지우기**를 고르기 전에는 삭제하지 않습니다.
